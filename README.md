## About This App

Android 用ベトナム語学習アプリ。単語は自分で登録するタイプですが、500語程度（英語で言うと小学生程度？）デフォルトで入ってます。
ベトナム語キーボードで使う前提です。

単語って何回も書かないと覚えられない、でもノートと鉛筆でデスクに座ってじっくり時間をかけて学習、なんて環境は学生くらいしかできない。
そこで"何度も繰り返し入力して覚える"というUX学習アプリを思い付き、なんとなくベトナム語学習アプリ作ってみました。
コーディングは Gemini3-flash Agent の力作です。 Android Studio 用。そのうちGoogle Play に公開しようかな。
